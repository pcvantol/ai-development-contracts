# Handoff

Start with [README.md](README.md), then read the canonical registry in
`contracts/contracts.json`, the relevant profile in `profiles/profiles.json`, and
the generated self projection in `docs/ai-development/`. Run
`python3 scripts/validate.py` before handing off a contract change. TDE is an
external product integration; its product architecture and evidence model are not
defined in this repository.
